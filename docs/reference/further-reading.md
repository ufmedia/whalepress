## Further reading

**Theme stack**

- [Timber 2 documentation](https://timber.github.io/docs/v2/) and its [cheat sheet](https://timber.github.io/docs/v2/guides/cheatsheet/). Required reading.
- [Twig documentation](https://twig.symfony.com/doc/3.x/) and [coding standards](https://twig.symfony.com/doc/3.x/coding_standards.html)
- [Tailwind CSS 4](https://tailwindcss.com/docs), especially [theme variables](https://tailwindcss.com/docs/theme) and [functions and directives](https://tailwindcss.com/docs/functions-and-directives)
- [Vite](https://vite.dev/guide/) and its [backend integration guide](https://vite.dev/guide/backend-integration)
- [Utopia fluid type and space](https://utopia.fyi)
- [theme.json reference](https://developer.wordpress.org/block-editor/reference-guides/theme-json-reference/theme-json-living/)

**WordPress**

- [Developer resources](https://developer.wordpress.org/)
- [WordPress Coding Standards](https://developer.wordpress.org/coding-standards/wordpress-coding-standards/)
- [Block editor handbook](https://developer.wordpress.org/block-editor/)
- [WP-CLI commands](https://developer.wordpress.org/cli/commands/)
- [Hardening WordPress](https://developer.wordpress.org/advanced-administration/security/hardening/)

**Tooling**

- [Docker Compose](https://docs.docker.com/compose/) and [BuildKit secrets](https://docs.docker.com/build/building/secrets/)
- [Composer](https://getcomposer.org/doc/) and [WordPress Packagist](https://wpackagist.org)
- [PHPStan](https://phpstan.org/user-guide/getting-started), [Rector](https://getrector.com/documentation), [Brain Monkey](https://giuseppe-mazzapica.gitbook.io/brain-monkey)
- [Playwright](https://playwright.dev/docs/intro) and [axe-core with Playwright](https://playwright.dev/docs/accessibility-testing)
- [Xdebug 3](https://xdebug.org/docs/) and [VS Code PHP Debug](https://marketplace.visualstudio.com/items?itemName=xdebug.php-debug)
- [semantic-release](https://semantic-release.gitbook.io) and [Conventional Commits](https://www.conventionalcommits.org)
- [GitHub Actions security hardening](https://docs.github.com/actions/security-for-github-actions/security-guides/security-hardening-for-github-actions)
